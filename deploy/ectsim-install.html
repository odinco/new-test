Install the ECT simulator on odinsys.net/ectsim

No download needed. Copy the code below and paste it into a new file in Hostinger's File Manager.

  1. Click Copy code below.
  2. In Hostinger hPanel, go to Websites → Manage (odinsys.net) → File Manager.
  3. Open public_html, click New folder, and name it ectsim.
  4. Open the ectsim folder, click New file, and name it index.html.
  5. Open the new file, paste with Ctrl+V (Cmd+V on Mac), and click Save.
  6. Visit odinsys.net/ectsim.
